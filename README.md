# JPE Wrestling GM

Retro 1992 fishtank-style wrestling management simulator.  
Single-file HTML game. Open `index.html` in any browser.

## How to Play
- Open `index.html` directly (double-click or drag into browser)
- Works great on desktop and mobile (PWA installable)
- All progress saves automatically to localStorage

## Dev Tools
Open browser console and type `JPE` to see available commands:
- `JPE.advanceDays(7)`
- `JPE.giveTP("GoldenMan", 10)`
- `JPE.signFreeAgent("BlazeVortex")`
- `JPE.exportSave()`
- `JPE.reset()`
